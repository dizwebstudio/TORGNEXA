# Спецификация коннектора «Долями»

- идентификатор: `dolyami`
- семейство: `payment`
- версия SDK: `1`
- авторизация: логин/пароль и mTLS-сертификат в одном callback-scoped секрете
- runtime-поверхность: отдельная карточка «Платежи», health-check

Официальная интеграция «Долями» использует методы Create, Cancel, Commit, Info
и Refund, а также вебхуки статусов. Для вызовов API сервис требует логин и
пароль партнёра и сертификат T-API/mTLS. Эти данные хранятся только в
SecretProvider; адрес проверки задаётся оператором как HTTPS runtime-параметр,
поскольку боевой и демо-домены выдаются персональным менеджером.

Текущая admission-грань TORGNEXA выполняет mTLS/basic проверку доступности
настроенного endpoint. Операции создания платежа, подтверждения, возврата,
получения статуса и приёма вебхуков не включены до qualification с демо-
кабинетом, синтетическими fixtures, проверкой подписи и идемпотентным
платёжным bridge.

Актуальные требования к подключению и сертификату описаны в [официальной
документации «Долями»](https://dolyame.ru/develop/api/preparation/) и в
[описании работы заявки](https://dolyame.ru/develop/api/application/).

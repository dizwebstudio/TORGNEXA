# Capability audit

Only capabilities demonstrated by the current official interface and Connector SDK v1 are admitted. CDEK OAuth client credentials are checked against the token endpoint and a bounded city-directory read; the access token is discarded after the probe. The host transport and application runtime expose bounded read-only delivery-point and rate-preview routes when `pickup.points.read` or `logistics.rates.read` is explicitly enabled. Rate requests accept up to 50 parcels and normalize at most 100 tariff results using fixed-decimal money parsing. The application returns neutral option identifiers; remote tariff/PVZ identifiers remain provider-local. Shipment, tracking, labels and returns remain closed until current fixtures, canonical service mapping, idempotent host routing and non-production qualification are retained. No browser-cookie automation, private editor endpoints, raw card credentials, or provider-specific Core branches are permitted.

Official documentation: https://apidoc.cdek.ru/

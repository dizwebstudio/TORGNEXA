# Shopware 6

Storefront connector. Self-hosted, OAuth2 client_credentials Integration credential, Shopware Admin API for products/inventory/prices/orders/returns. Product create and webhook receipt are unsupported by design (see capability-audit.md). The disposable Docker qualification is documented in [docker-live-qualification.md](docker-live-qualification.md); its current result is recorded in [live-qualification-status.json](live-qualification-status.json).

Official documentation: https://developer.shopware.com/docs/guides/integrations-api/

# Спецификация коннектора М.Видео

- идентификатор: `mvideo`
- семейство: `marketplace`
- версия SDK: `1`
- авторизация: API key, передаваемый только через SecretProvider
- runtime-поверхность: отдельная карточка «Маркетплейсы», health-check

Манифест фиксирует минимальный SDK-контракт чтения товаров, остатков и
заказов. В production runtime доступна только проверка подключения к
операторскому HTTPS endpoint. Endpoint и формат credentials не угадываются и
не подменяются старым или не подтверждённым API: их задаёт оператор после
получения актуального партнёрского доступа.

Товарная синхронизация, заказы, цены, остатки, webhooks и публикация остаются
закрытыми до отдельной квалификации текущего API М.Видео, fixtures и
идемпотентного worker bridge.

# План conformance для ПЭК

`connectors/logistics/pek` содержит sandbox-кандидат и детерминированные тесты без сети,
боевых ключей, адресов получателей и персональных данных.

Проверяются:

1. валидация и нормализация тарифов;
2. создание и чтение статуса отправления;
3. чтение отделений/ПВЗ;
4. callback-scoped доступ к секрету;
5. tenant isolation, rate-limit и idempotency probes общего harness.

Перед включением записи в production необходимо получить тестовый аккаунт ПЭК,
зафиксировать текущую версию API, добавить записанные (обезличенные) fixtures
и пройти повторяемость create/status на одном idempotency key.

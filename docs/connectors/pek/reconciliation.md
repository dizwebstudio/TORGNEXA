# Сверка ПЭК

Статус груза ПЭК является удалённо-авторитетным наблюдением. После допуска
host-side logistics bridge должен сохранять только внутренний идентификатор
кабинета, канонический remote ID и нормализованный статус с временем
наблюдения. Сырые ответы API и данные получателей не сохраняются.

На текущем этапе приложение выполняет только проверку доступа из карточки
«Доставка». Планировщик сверки и автоматическая подача заявок не включены;
это исключает повторную отправку при неоднозначном ответе API.

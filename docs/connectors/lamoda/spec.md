# Спецификация коннектора Lamoda

- идентификатор: `lamoda`
- семейство: `marketplace`
- версия SDK: `1`
- авторизация: API key, передаваемый только через SecretProvider
- runtime-поверхность: отдельная карточка «Маркетплейсы», health-check

Манифест фиксирует минимальный SDK-контракт чтения товаров, цен, остатков и
заказов. В текущем production runtime эти возможности не включены: оператор
может сохранить ключ и указать HTTPS endpoint актуального Seller API для
проверки подключения. Полный Seller API bridge, курсоры, маппинг remote ID,
идемпотентность и worker-диспетчеризация требуют отдельной квалификации.

Публичная [документация Lamoda](https://academy.lamoda.ru/articles/api/intro/00_overview/) описывает Seller API v2; конкретный набор
доступных методов и scopes зависит от договора и кабинета партнёра и поэтому
не зашивается в общий runtime-контракт.

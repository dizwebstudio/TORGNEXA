# Аудит возможностей Lamoda

Lamoda добавлена в каталог как отдельная marketplace health-check surface.
Наличие Seller API и SDK-манифеста не используется как доказательство
готовности товарной синхронизации: доступные scopes, лимиты и форматы
ответов проверяются только на конкретном партнёрском кабинете.

Admitted в текущем runtime:

- tenant-scoped сохранение API key через SecretProvider;
- bounded HTTPS health probe к endpoint, который указывает оператор;
- нормализация доступности и отказа без сохранения ответа провайдера.

Не admitted: чтение/запись товаров, цены, остатки, заказы, webhook,
рекламные и финансовые операции. Для их включения нужны актуальная версия
Seller API, обезличенные fixtures, тестовый кабинет и отдельный reviewed
worker bridge с идемпотентностью и reconciliation.

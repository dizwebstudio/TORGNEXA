# Shopify Connector Spec

Family: `storefront`. OAuth2 authorization-code, per-tenant host (`{shop}.myshopify.com`), pinned Admin REST API `2026-07` for products/inventory/prices/orders/returns, with the official GraphQL Admin API used only for exact variant-SKU lookup before product creation. Shopify marks Admin REST as legacy for new apps; migration of the remaining resource operations to GraphQL Admin API is a follow-up task, not silently mixed into this connector.

Production networking is host-injected through a typed transport; provider code has no direct Core or SQL authority. The per-tenant OAuth host is resolved generically by the host-owned OAuth runtime's `HostParameter`/`HostSuffix` template mechanism, not by any Shopify-specific branch in the app layer. Pagination follows Shopify's cursor (`page_info`/Link header) contract, not page numbers. Product create (`RemoteID == ""`) first searches `productVariants` with an exact SKU, rejects multiple matching products or an incomplete page, creates one default-variant product through REST, and verifies the returned product, title, description, status and SKU. If the create response is ambiguous, the same exact lookup and verification reconcile the result; failure to establish one result remains fail-closed. Webhook receipt is deliberately unsupported: Shopify signs webhooks with the OAuth app's shared client secret, which the host-owned OAuth runtime does not currently expose to a per-account connector adapter.

Official documentation: https://shopify.dev/docs/api/admin-rest/latest ; API versioning: https://shopify.dev/docs/api/usage/versioning ; development stores: https://shopify.dev/docs/apps/build/stores/development-stores

# Capability audit

Only capabilities demonstrated by the current official interface and Connector SDK v1 are admitted. `products.write` supports exact-SKU create and update: Shopify's GraphQL Admin `productVariants` search establishes the idempotency lookup, the REST `POST /products.json` endpoint performs creation, and every mutation is followed by a read-after-write check. An ambiguous create is reconciled by repeating the exact SKU lookup; the adapter returns `write_outcome_unknown` if that lookup cannot establish one matching product. `notifications.receive` is declared but returns `unsupported`: this connector has no scoped access to the OAuth app's shared client secret Shopify's webhook HMAC requires. `orders.status.write` supports only the three unambiguous single-call order lifecycle transitions Shopify's REST API exposes directly (cancel/close/reopen); marking an order fulfilled is out of scope because it is a distinct sub-resource requiring line-item detail this SDK's single `StatusRemoteID` contract cannot carry. No browser-cookie automation, private editor endpoints, raw card credentials, or provider-specific Core branches are permitted.

Official documentation: https://shopify.dev/docs/api/admin-rest

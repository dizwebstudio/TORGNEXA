# Capability audit

Only capabilities demonstrated by the current official interface and Connector SDK v1 are admitted. `products.write` supports update only: create is declared in the manifest for interface completeness but returns a normalized `unsupported` remote error, since Shopify's REST API cannot safely search by SKU to guarantee idempotent creation. `notifications.receive` is declared but likewise returns `unsupported`: this connector has no scoped access to the OAuth app's shared client secret Shopify's webhook HMAC requires. `orders.status.write` supports only the three unambiguous single-call order lifecycle transitions Shopify's REST API exposes directly (cancel/close/reopen); marking an order fulfilled is out of scope because it is a distinct sub-resource requiring line-item detail this SDK's single `StatusRemoteID` contract cannot carry. No browser-cookie automation, private editor endpoints, raw card credentials, or provider-specific Core branches are permitted.

Official documentation: https://shopify.dev/docs/api/admin-rest

# План conformance для «Почты России»

`connectors/logistics/pochta-russia` содержит sandbox-кандидат и
детерминированную проверку здоровья без сети и боевых credentials. Общий
harness проверяет SDK v1, границу секретов, нормализацию ошибок, tenant
isolation, egress и sandbox.

Перед включением тарифов, оформления отправлений, документов и трекинга
необходимо получить тестовый доступ к API «Отправка», зафиксировать текущую
версию REST/SOAP-контрактов, добавить синтетические fixtures и проверить
безопасное восстановление после неоднозначного ответа.

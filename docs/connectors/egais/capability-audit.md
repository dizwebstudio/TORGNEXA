# Capability audit

Only capabilities demonstrated by the current official interface and Connector SDK v1 are admitted. UTM is the local official transport boundary. Regulated writes require an existing signed/released artifact, approval reference and idempotency key; unsupported document kinds remain explicit and remote tickets/status are authoritative. No browser-cookie automation, private editor endpoints, raw card credentials, or provider-specific Core branches are permitted.

Official documentation: https://egais.ru/files/Doc_utm_420.pdf

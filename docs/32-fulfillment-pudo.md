# Fulfillment, Logistics & Pickup Points

Model warehouses, shipments, carriers, courier delivery, pickup points/PUDO, routing, tracking, storage and returns.

PickupPoint supports external marketplace/carrier points and own/franchise/store pickup locations. Capability model covers receive/store/issue/return/payment/capacity.

Routing policies may optimize cost, ETA, capacity and SLA. Remote shipment/pickup status participates in reconciliation.

Own PUDO operational UI can later add scanning, shelf placement, issue, fiscalization and returns without changing logistics SDK.

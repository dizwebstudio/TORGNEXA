# Task 143: ПЭК logistics connector

## Status

`repository-complete` — 2026-08-28. ПЭК доступен в отдельном контуре
«Доставка» для создания кабинета, шифрованного сохранения credentials и
проверки подключения.

## Objective

Добавить ПЭК в каталог без фиктивной товарной синхронизации и с максимальным
безопасным покрытием проверки до получения тестового кабинета перевозчика.

## Acceptance

- ПЭК отображается в семействе «Доставка»;
- Basic-логин и ключ доступа не покидают SecretProvider;
- проверка соединения использует официальный API личного кабинета;
- SDK-тесты и conformance-кандидат выполняются без сети и production secrets;
- операции записи остаются qualification-gated до фиксации актуальных fixtures.

## Qualification

Официальная документация ПЭК подтверждает Basic-аутентификацию, JSON POST и
методы расчёта, заявок, статусов и справочников. Для включения боевых заявок
нужны тестовый аккаунт, обезличенные fixtures и проверка повторов по одному
idempotency key.

# ADR-0150 — форма Ф103 партии Почты России

Status: Accepted

## Context

Официальная спецификация API «Отправка» содержит отдельную генерацию формы
Ф103 для партии. Runtime уже умел читать PDF формы заказа, возвратную
этикетку и состояние партий, но документ Ф103 оставался fail-closed.

## Decision

Расширить существующий `LabelRequest` Почты России явным форматом
`batch_f103_pdf`. Host transport вызывает `GET /1.0/forms/{batch-name}/f103pdf`
на фиксированном `otpravka-api.pochta.ru`, принимает только числовой номер
партии, проверяет HTTP 2xx, `application/pdf` и сигнатуру `%PDF-`. Наружу
выходит только content-addressed opaque `ArtifactRef` с префиксом
`pochta-russia:form:batch-f103:`.

Форматы `pdf` и `return_pdf` не меняются. Capability, Core-модель, база данных
и секретная модель не меняются: используется существующий tenant-scoped
permission/API путь чтения PDF-документа.

## Security and privacy impact

Токен и ключ пользователя остаются callback-scoped в SecretProvider. PDF,
состав партии и сырой ответ не попадают в SDK, события, audit или логи.
Номер партии проверяется и ограничивается до provider egress; caller не
управляет host или URL провайдера.

## Compatibility impact

Изменение обратно совместимо: существующие форматы и ответы не меняются.
Клиент должен явно передавать `format=batch_f103_pdf`. Публичный endpoint
остаётся прежним, меняется только согласованный формат запроса и его runtime
admission.

## Operational impact

Форма строится по одной партии, идентифицированной номером, полученным из
bounded batch projection. Пустая, архивная или недоступная для печати партия
не превращается в успешный документ: ошибка провайдера передаётся оператору.
Live qualification должна использовать тестовую партию.

## Migration and data impact

Миграция не требуется. Используется существующая граница label operation и
lineage; сохраняется только непрозрачная ссылка на проверенный PDF.

## Alternatives considered

Оставить форму Ф103 fail-closed отвергнуто: официальный документ и точный
read-only endpoint известны, а существующий transport уже проверяет PDF.
Создавать отдельный Core endpoint отвергнуто: результат имеет тот же
provider-neutral artifact contract и должен проходить те же security/egress
границы.

## Consequences

Оператор может получить Ф103 из карточки подключённой Почты России рядом с
другими документами партии. Архивирование, передача партии в работу,
формирование новых партий и прочие неподтверждённые документы не изменяются.
